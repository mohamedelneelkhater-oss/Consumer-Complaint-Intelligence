# Consumer Complaint Intelligence

Automatically route a written consumer complaint to its financial product category.
Course project (Instant) - end-to-end NLP pipeline with a Streamlit web app.

## Results (test set, 24,362 complaints, 5 classes)

| Model     | Accuracy | Precision | Recall | F1 (weighted) |
|-----------|----------|-----------|--------|---------------|
| **GRU**   | 0.8757   | 0.8778    | 0.8757 | **0.8764**    |
| LSTM      | 0.8753   | 0.8764    | 0.8753 | 0.8754        |
| SimpleRNN | 0.5811   | 0.4716    | 0.5811 | 0.4546        |

The GRU model is used in the app.

## Categories

credit card, credit reporting, debt collection, mortgages and loans, retail banking.

## Pipeline

1. Cleaning: lowercase, remove masked text (XXXX), punctuation and digits, stop-word removal, lemmatization
2. Stratified split: 70% train / 15% validation / 15% test
3. Keras tokenizer (10,000 words), padding to 150 tokens
4. Embedding (128) + SimpleRNN / LSTM / GRU (64 units) + Dense head
5. Evaluation: accuracy, precision, recall, F1, confusion matrix

## Run locally

```bash
pip install -r requirements.txt
streamlit run app_streamlit.py
```

## Deploy on Streamlit Community Cloud

1. Push this repository to GitHub (including `model/` and `data/`).
2. Go to https://share.streamlit.io and sign in with GitHub.
3. Click **Create app**, choose the repository, branch `main`, and main file `app_streamlit.py`.
4. Click **Deploy**.

## App features

- **Single complaint:** type or pick an example, get the predicted category and a probability bar for every class.
- **Batch classification:** classify the bundled sample or your own CSV, see accuracy when a `label` column exists, and download the predictions.
